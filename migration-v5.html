▶Full-Stack Swap Boundary

The migration is not a single class swap. The real stack is layered, and several layers below and above ScExoPlayer carry behavior that Media3 does not currently reproduce.

L5 Consumers and wrappers: ScMediaVideoLayerViewController, OperaScMediaPlayer, UnifiedMediaPlayer, TimelinePlayer, TimelinePlayerV2
Do not swap independently These layers assume advanced features like alternate audio, multiple track players, renderer configuration, scrubbing, and timeline-aware behavior.
L4 Routing and session creation: MediaPlayerFactoryImpl, config flags, future engine selector
Requires capability-aware routing Current routing is a boolean switch, not a truthful eligibility policy.
L3 Player core: ScExoPlayer, ExoMediaPlayer, Media3MediaPlayer
Center of dependency graph ScExoPlayer owns task execution, analytics hooks, media-source integration, renderer messaging, locale/seek/scrubbing/state behavior, and metadata/reporting hooks.

Mostly not direct swaps Some are public-API package migrations; others are semantic rewrites or fork-dependent.

Often reusable with adapters These are closer to stable public APIs or platform APIs, but still need integration work.
L0 Library surface: ExoPlayer vs Media3 packages

▶ScExoPlayer Deep Dive

Core files in the chain

playback/core/player/ScExoPlayerFactory.kt → builds ScExoPlayer with a fresh MediaSourceManager
playback/core/player/ScExoPlayer.kt → task executor + ExoPlayer wrapper + analytics + renderer + track/source coordination
playback/core/player/MediaSourceManager.kt → playlist composition, alternate audio, concatenation/merging, media source mutation

Direct dependencies that matter semantically

  • PlaybackComponents: renderers factory, track selector, load control, bandwidth meter, media source factory.
  • MediaSourceManager: not just "source creation" but playlist mutation, alternate audio injection, merging, and clipping behavior.
  • Task executor/threading: almost every mutating method is marshalled through a dedicated executor instead of calling the player directly.
  • Analytics/reporting: PlayerAnalyticsListener, timeline listeners, debug listeners, and player context reporting.
  • Renderer message bus: renderer configuration, renderer component injection, playback looper messaging, experiment config, renderer listener setup.

Why replacing it with current Media3 is unsafe

  • Current Media3MediaPlayer does not implement renderer configuration, renderer component injection, scrubbing mode, preferred locale, media metadata provider, or alternate audio routing.
  • ScExoPlayer exposes timeline-aware methods like absolute position and segment-aware seeking that the current Media3 path does not.
  • ScExoPlayer is integrated with cache-aware track selection, bandwidth/debug hooks, playback analytics, and richer error handling.
  • Several wrapper layers assume those capabilities are real, not optional.
Bottom line: the current Media3 path is a simple player implementation. ScExoPlayer is a platform subsystem.

PR: Replace boolean switch with capability-driven engine selection

Codex recommendation: Instead of a single boolean useMedia3Player, define a Media3Eligibility policy that evaluates each playback request against what Media3 currently supports. This prevents unsupported requests (alternate audio, preview/edit, scrubbing, renderer injection) from silently routing into incomplete Media3 behavior.

// PlaybackEngineSelector.kt (new) class PlaybackEngineSelector( private val useMedia3Flag: Boolean, private val eligibilityPolicy: Media3EligibilityPolicy ) { fun selectEngine(request: PlaybackRequest): EngineChoice { if (!useMedia3Flag) return EngineChoice.EXOPLAYER val eligibility = eligibilityPolicy.evaluate(request) return when { eligibility.isEligible -> EngineChoice.MEDIA3 else -> { log("Media3 ineligible: ${eligibility.reason}") EngineChoice.EXOPLAYER // safe fallback } } } } // Media3EligibilityPolicy.kt (new) class Media3EligibilityPolicy { fun evaluate(request: PlaybackRequest): Eligibility { // Phase 1: only simple single-video playback if (request.hasAlternateAudio) return ineligible("alternate audio") if (request.hasRendererConfig) return ineligible("renderer config") if (request.isPreviewOrEdit) return ineligible("preview/edit") if (request.requiresScrubbing) return ineligible("scrubbing") if (request.hasSubtitles) return ineligible("subtitles") return eligible() } }
